# Issue types

Each process declares which of these it accepts via its `issue_types` field. Type is set at creation and immutable.

## `bug` — Bug

Defect in shipped behavior — something is broken or wrong.

**GitHub Issue Type**: `Bug` · **Color**: `red`

## `feature` — Feature

New user-facing capability or enhancement to existing behavior.

**GitHub Issue Type**: `Feature` · **Color**: `green`

## `task` — Task

Tracked work that isn't a bug or feature — refactors, dependency bumps, infrastructure changes.

**GitHub Issue Type**: `Task` · **Color**: `blue`
